# Terminal and Linux Fundamentals

This directory contains my notes and practice files about the Command Line Interface (CLI).

## Commands I've Learned

| Command | Description |
| :--- | :--- |
| `pwd` | Print Working Directory (Shows where I am) |
| `ls` | List files and directories |
| `cd` | Change Directory (Navigate between folders) |
| `mkdir` | Make Directory (Create a new folder) |
| `touch` | Create a new empty file |
| `clear` | Clear the terminal screen |

## Practice Notes
- I learned how to navigate through the file system using the `cd` command.
- I practiced creating nested directories and managing files from the terminal.
- I'm getting comfortable with using the CLI instead of the GUI.
